# Admin

From 3.0 the core templates and screen layouts are part of the application and installed by `bin/console app:update`.
In 2.x the admin is built without the following, that therefore need to be installed afterwards: 
 - [Templates](../content_structure/templates)
 - [Layouts](../content_structure/layouts)
 - [Feeds](../content_structure/feeds)
 - [Themes](../content_structure/themes)

Please also look at the readme for structure between elements in the admin.
